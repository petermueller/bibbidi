# Add or Change a Command / Module / Type

**Command and type modules are generated.** Everything under `lib/bibbidi/commands/` and
`lib/bibbidi/types/` carries `# Generated by mix bibbidi.gen — do not edit manually` and is
overwritten on the next `mix bibbidi.gen`. Never hand-edit them. To change a command,
module, or type, change the *source* (the CDDL spec or the generator) and regenerate.

The generated shape (so tests and callers match): commands are structs invoked via
`connection_mod.execute(conn, %CommandStruct{}, [])`, with typed `.opts()`/`.result()` and
`Bibbidi.Types.*` parameter types — not the old `Connection.send_command/3` + `put_opt`
pattern.

Run commands from `packages/bibbidi/`.

## Workflow

1. **Find the definition in the CDDL spec.** `priv/cddl/remote.cddl` defines what the client
   sends (commands); `priv/cddl/local.cddl` defines what it receives (responses/events).
   Introspect with `mix bibbidi.cddl.inspect` instead of ad-hoc `mix run -e`:
   ```bash
   mix bibbidi.cddl.inspect --commands network          # commands in a module
   mix bibbidi.cddl.inspect --fields network.AddInterceptParameters
   mix bibbidi.cddl.inspect --search intercept
   ```

2. **Make the change at the source — pick the right layer:**
   - **Spec is out of date / missing the command** → refresh with `mix bibbidi.download_spec`,
     or patch `priv/cddl/{remote,local}.cddl` directly.
   - **Generated structure/output is wrong** → edit the generator in
     `dev/cddl/generator.ex` (Elixir emitted) or `dev/cddl/parser.ex` (CDDL parsing).
   - **Module/field casing is wrong** (e.g. `Html` instead of `HTML`, `Base64value` instead
     of `Base64Value`) → edit `dev/cddl/utils.ex`. Casing delegates to
     `Macro.underscore`/`Macro.camelize` plus an explicit acronym list.

3. **Regenerate.** Use the `regen-codegen` skill (wipe every generated file, `mix bibbidi.gen
   --yes`, eyeball the diff, verify). A full wipe is required because path changes leave
   stale duplicate files behind.

4. **Add or adjust the hand-written tests** (these are *not* generated):
   - Unit: `test/bibbidi/commands/<module>_test.exs` using `Bibbidi.MockTransport`.
   - Integration: `test/integration/<module>_test.exs` tagged `:integration` — use the
     `write-integration-test` skill.

## Checklist

- [ ] Change made in the CDDL spec or `dev/cddl/*`, never in a generated file
- [ ] `mix bibbidi.cddl.inspect` used to confirm the rule shape
- [ ] Regenerated via `regen-codegen`; diff is intentional and focused
- [ ] Hand-written unit + integration tests added/updated
- [ ] `mix compile --warnings-as-errors` and `mix test` pass
