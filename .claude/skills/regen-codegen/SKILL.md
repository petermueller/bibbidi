# Regenerate CDDL Codegen

Use whenever `dev/cddl/{parser,generator,utils}.ex` or `priv/cddl/*.cddl` changes. The
codegen overwrites at paths it computes; when those paths shift (e.g. acronym handling,
snake_case rules), stale files linger unless they are wiped and regenerated. Don't
de-dupe by hand — just delete everything generated and re-run.

Run from `packages/bibbidi/`.

## Steps

```bash
# 1. Wipe every generated file
grep -rl "Generated by mix bibbidi.gen" lib/ | xargs rm

# 2. Regenerate from CDDL + dev/
mix bibbidi.gen --yes

# 3. Eyeball the diff
git status

# 4. Verify nothing broke
mix test
```

## Notes

- The marker `# Generated by mix bibbidi.gen — do not edit manually` is on every generated
  file. The grep is safe — hand-written files (e.g. `Bibbidi.Events.Unknown`) lack the
  marker and survive.
- Clean working tree after regen = the change was effectively a no-op. Focused diff =
  intentional behaviour change. Unexpected diff = bug.
- If `mix bibbidi.gen` fails with a CompileError on a previously-generated file, an earlier
  run wrote broken Elixir. Recover with `git checkout -- lib/` and rerun — codegen changes
  in `dev/` are untouched.
- To verify a single naming rule, prefer `mix bibbidi.cddl.inspect` over ad-hoc
  `mix run -e` scripts. The codegen delegates casing to `Macro.underscore`/`Macro.camelize`
  plus an explicit acronym list (e.g. `HTML`, `XPath`, `Base64`).
