Don't use "cf." in prose. Use "see" instead.

**Why:** the user finds "cf." pretentious / ridiculous.

**How to apply:** anywhere prose-style references another thing — docs, commit
messages, code comments, conversations, plan files. `e.g.` and `i.e.` are fine
(they're shorter and idiomatic). Other Latin abbreviations are case-by-case
but bias toward plain English.
